# Slime Brawlers

A fast-paced 2D pixel-art arcade platform fighting game featuring slimes with unique stats, passive traits, and special abilities!

## 🎮 Play Online
Play directly in your browser on GitHub Pages:
👉 **[https://chroma-debug.github.io/slime-brawlers/](https://chroma-debug.github.io/slime-brawlers/)**

## ✨ Features
- **11 Playable Characters**:
  - Classic Slimes: Gloop, Volt, Ember, Frost, Rocky, Void, Twin, God, Ruby, Hatter
  - **Special Character**: **Jack the Lantern** with pumpkin bomb specials and fiery soul flame attacks!
- **Game Modes**:
  - Arcade Mode & VS CPU
  - Sumo Mode
  - Survival Mode
  - 2 Player Local PvP
- **Quests & Unlocks**: Complete challenges to unlock slimes, skins, and trophies!
- **Auto-Save**: Progress is automatically saved in your browser.

## 🕹️ Controls
- **Movement**: Arrow Keys or WASD
- **Jump**: Up / W / Space
- **Attack**: J / Z (Light Attack)
- **Heavy / Special**: K / X (Heavy Attack) & L / C (Special Ability)
- **Block / Parry**: Down / S / Shift
